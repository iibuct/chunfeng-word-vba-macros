## ✨ 功能说明

本项目是一套面向 Word 长文档排版的 VBA 宏工具箱，主要用于论文、报告、技术文档中公式、图片、表格、题注、样式、编号和页面格式的批量处理与统一。主要功能包括：

- **公式、图片、表格、Visio 定位导航**：支持在 Word 新式公式、旧版公式、MathType 公式、嵌入型图片、浮动图片、表格和 Visio 嵌入对象之间前后跳转与选中。
- **图片批量处理**：批量修改图片缩放比例、图片宽度，保持宽高比；处理嵌入式图片、浮动图片、组合图形和文本框内图片；为图片所在段落或下方图题应用 `BG图行`、`BG图题` 等样式。
- **表格批量处理**：批量设置表格样式、列宽、行高、自适应窗口、标题行重复、首行样式、表格序号填充、表格居中和字体格式。
- **样式创建与应用**：一键创建 `BG正文缩进`、`BG正文顶格`、`BG图行`、`BG图题`、`BG表题`、`BG表文`、`BG表首行`、`BG公式` 等基础样式；支持 BK、TOC、标题系列样式的批量创建、修改和快速应用。
- **题注、编号与交叉引用**：插入图、表、公式编号；支持带章节号编号；插入下方最近的图题注或表题注交叉引用；章节标题多级自动编号；自动编号转文本。
- **页面与段落格式**：统一页边距、页眉页脚距离、纵向页面页边距；插入横向页面；批量修改标题样式、段落格式、与下一段同页、软换行转硬换行等。
- **文本与实用工具**：英文双引号转中文引号、纯文本粘贴、Zotero 引用改蓝色、英文括号上移、批注作者修改、批注导出、清除页眉横线、删除未使用样式、删除百分号开头段落等。
- **兼容与稳定性处理**：识别并排除 MathType、Equation、Visio、Zotero 等第三方对象；使用屏幕刷新控制、倒序遍历、错误捕获和进度提示提升长文档批量处理稳定性。

> 注意：部分宏依赖文档中已存在的自定义样式，如 `BG图行`、`BG图题`、`BG表题`、`BG表文`、`BG表首行`、`BG公式`、`MTDisplayEquation` 等。首次使用时可先运行“一键创建样式”相关宏；涉及 Visio、MathType、Zotero 的功能需要相应对象或插件生成的内容。

## 📥 安装顺序（Windows Word）

> 适用于包含 `WT_Legacy.bas`和 `.exportedUI` 的 Word 宏工具箱。请严格按顺序操作，避免模块重名、旧版并存或功能区导入失败。

1. **打开 Word，按 `Alt + F11` 进入 VBA 编辑器。**
2. **找到想让所有 Word 文档都能调用的项目**，推荐 `Normal`（Normal.dotm），或确保你的自定义 `.dotm` 模板始终加载。
3. **【文件 → 导入文件】**分别导入 `WT_Legacy.bas` 。
4. 如果已导入过旧版同名模块，先备份并移除旧模块再导入，**不要把旧版与新版并存**。如果还有原始宏模块，且包含相同的公开过程名，也应先导出备份，再移除旧副本，以避免“名称不明确”。
5. 执行 VBA 编辑器 **【调试 → 编译 VBAProject】**，确认 Word 没有继续提示编译错误，保存 `Normal.dotm` / 模板。
6. **退出 Word 并重新启动。**
7. Word **【文件 → 选项 → 自定义功能区 → 导入/导出 → 导入自定义文件】**，选择 `.exportedUI`。
8. 确保 Word 宏安全策略允许已可信的模板运行；**不要为了本工具而全局启用不明来源的宏**。
